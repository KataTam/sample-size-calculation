# Pilot student feedback

Complete after the session. This form measures experience and confidence, not change in conceptual knowledge. Use `pilot_learning_assessment.md` for actual pre/post learning assessment. Names are not required.

Date, course, duration, outcome case, live app or static route:

Rate each item from 1 (not at all) to 5 (very much), with “not used” where appropriate:

1. I can explain why assumptions matter to sample-size decisions.
2. I can explain the difference between one study and repeated studies.
3. I can interpret precision alongside clinical importance.
4. The interface or prepared outputs were readable and easy to use.
5. The session allowed enough time to interpret results.

Which activity helped most, and why?

Which concept was confusing or too fast?

Did any device, keyboard, screen reader, connection or software issue prevent participation?

What would you change in the case, explanation or activity?
