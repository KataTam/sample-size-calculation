# Public consolidation — 22 September 2026

sample-size-calculation is the single active public project. It includes the maintained tutorial, shared calculations, four app sources, bibliography, teaching/case materials, static simulated data, collaborator review documents and the early sample-size browser prototype. It starts with a reviewed source snapshot. The former source repository remains a private archive, and the former app repository is retained for compatibility redirects.

GitHub Actions generates and deploys the book, standalone HTML, browser apps and source ZIP together on each push to main. Edit module/Sample_size_open_module.Rmd; do not maintain separate HTML copies.

Full old Git history, legacy lecture-derived drafts, third-party screenshots and reading PDFs, local shell histories and environment caches remain outside the public project. Randomization experiments remain a separate project. Local legacy folders are retained as backups.
