# Open Education References For The Sample Size OER

These references were selected to support the committee recommendation to provide teaching documentation alongside the open-source R Markdown/Shiny tool, especially documentation that makes constructive alignment explicit between learning outcomes, interaction with the tool, and assessment.

## Verified PDFs

1. `Paskevicius_2017_OEP_constructive_alignment.pdf`
   - Most directly relevant source.
   - Use it to justify an educator guide structured around learning outcomes, learning resources, teaching/learning activities, and assessment/evaluation.
   - Useful design idea: include an alignment table for every activity in the module.

2. `Paskevicius_Irvine_2019_open_pedagogy_learning_design.pdf`
   - Useful for explaining how open pedagogy changes learning design beyond simply sharing free content.
   - Supports student co-creation, public-facing work, peer feedback, and community-engaged learning.

3. `Cronin_MacLaren_2018_conceptualising_OEP_review.pdf`
   - Broader review of open educational practices.
   - Useful for terminology, definitions, and positioning the module as open practice rather than only an open resource.

4. `Bothmann_2021_open_source_educational_resources_data_science.pdf`
   - Useful because it discusses open source educational resources in computational/data-science teaching.
   - Supports sharing source files, reproducible examples, open development, and adaptation by other instructors.

5. `Valle_2026_OER_barriers_open_issues.pdf`
   - Recent OER barriers paper.
   - Useful for explaining why the module should include implementation notes, accessibility notes, source files, adaptation guidance, and maintenance information.

## Suggested Documentation To Add To The R Markdown Module

Add an educator-facing section or separate `TEACHING_GUIDE.md` with:

- module purpose and target audience
- intended learning outcomes
- prerequisite knowledge
- recommended use in 30, 60, and 90 minute teaching formats
- constructive-alignment table linking each outcome to tool interactions and assessment evidence
- assessment prompts and rubrics
- student co-creation options
- adaptation notes for other courses
- accessibility checklist
- license, citation, and reuse instructions
- maintenance/versioning notes
