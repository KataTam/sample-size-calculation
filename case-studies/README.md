# Case studies

Start with the [chronic pain example](chronic_pain_case.md), then use the [student case and assumption map](student_case_template.md) to develop a hypothetical study or a question supported by public evidence.

The additional cases show how the research question changes the purpose of a calculation:

- [Rehabilitation improvement](rehabilitation_case.md): compare two independent mean improvement scores, distinguishing clinical threshold and planning effect.
- [Adherence support](adherence_case.md): compare independent binary outcomes, then consider a smaller actual effect and loss to follow-up.
- [Discharge pathways](discharge_case.md): distinguish relative change from an absolute proportion difference.
- [Prevalence survey](prevalence_case.md): estimate one proportion with useful absolute precision.
- [Pilot feasibility](pilot_feasibility_case.md): assess retention precision with a fixed resource limit.

1. State the clinical question and planning goal.
2. Record assumptions, their sources and plausible alternatives.
3. Predict a consequence before exploring the tutorial or app.
4. Interpret the results and justify a feasible design.

Use the [quality checklist](case_quality_checklist.md) and [peer-review form](peer_review_form.md) to improve a draft. Teachers can use the [instructor review notes](instructor_review_notes.md).

The treatment-comparison cases use two independent, equally allocated groups. The prevalence and pilot process-measure examples use one independent sample. Other designs require appropriate methods: consult the [study-design guide](../student-materials/study-design-guide.md). Do not include identifiable patient information. Clearly label invented values as teaching assumptions.
