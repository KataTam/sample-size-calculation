# Instructor Review Notes For Student-Generated Cases

These notes help instructors decide how to use student-generated cases in class or in a later version of the OER.

## Possible Uses

Student cases can be used as:

- in-class discussion examples
- peer-review exercises
- revised examples for a future cohort
- public OER examples, only with consent and review

## Review Criteria

Before using a case beyond the original assignment, check:

- the clinical context is clear
- the outcome type is correct
- assumptions are plausible enough for teaching
- calculations are correct
- per-group and total sample sizes are distinguished
- dropout adjustment is correct if included
- feasibility and ethics are discussed
- no identifiable patient information is present
- no confidential local project information is included
- the student has consented to reuse and attribution

## Consent And Attribution

If a student case is reused publicly:

- ask for explicit consent
- let the student choose whether to be named, anonymized, or acknowledged as part of a class group
- explain that the case may be edited for clarity, accessibility, or correctness
- keep a record of the consent decision outside the public repository

Suggested attribution wording:

> Adapted from a student-generated case developed in [course name], [year], with permission.

## Editing Student Cases

When revising a student case for reuse:

- preserve the clinical idea where possible
- simplify details that distract from the sample size decision
- remove any sensitive or identifying information
- check the calculation independently
- align the case with the module terminology
- add a short teaching note if the case has a useful misconception or discussion point

## When Not To Reuse A Case

Do not reuse a case publicly if:

- it contains identifiable patient information
- it appears to describe an active confidential study
- assumptions are too implausible to revise easily
- the student has not consented
- the case would require extensive rewriting beyond recognition
