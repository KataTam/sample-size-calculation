# Public consolidation — 22 September 2026

sample-size-calculation is the single active public project. It includes the maintained tutorial, shared calculations, four app sources, bibliography, teaching/case materials, static simulated data and the early sample-size browser prototype. It starts with a reviewed source snapshot. The former source repository remains a private archive, and the former app repository is also a private archive; the old Pages address is retired.

GitHub Actions generates and deploys the book, standalone HTML, browser apps and source ZIP together on each push to main. Edit module/Sample_size_open_module.Rmd; do not maintain separate HTML copies.

Full old Git history, legacy lecture-derived drafts, third-party screenshots and reading PDFs, local shell histories and environment caches remain outside the public project. Randomization experiments remain a separate project. Local legacy folders are retained as backups.


## Public-facing revision

The collaborator folder was removed by the author. It is no longer included in the website or source bundle. The current review route is in student-materials/. Case resources are now in case-studies/, and maintenance/rationale documents are grouped in documentation/.
