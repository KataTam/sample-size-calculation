# Flashcards

Short question-and-answer cards accompany the tutorial. Core covers the basic planning route; Core + Advanced includes the additional designs and methods. The cards are grouped by level. Each question in Anki and the preview links to the relevant tutorial explanation. All numerical examples are hypothetical.

## Try the Anki Core deck

1. Download the Core `.apkg` file.
2. In Anki Desktop, choose File → Import and select the file. The package includes its question-and-answer layout; no column mapping is needed.
3. Open Sample size tutorial → Core, then choose Study Now.
4. Think of your answer, choose Show Answer, and rate how well you recalled it. Anki schedules the next review from your response.

Anki may initially show fewer new cards than the full deck contains because of its daily study limit. The Browse window shows all imported cards.

The Core + Advanced package contains the same core cards plus 81 advanced cards. Importing it later adds an Advanced subdeck under the same Sample size tutorial parent. Existing core cards are recognized by stable identifiers. Select the parent deck to study both levels, or select Core alone. Importing Core after the combined package does not remove Advanced. Neither package contains another learner's review history.

If you edit cards yourself, check Anki's update options before reimporting a later release. [Anki's packaged-deck documentation](https://docs.ankiweb.net/importing/packaged-decks.html) explains importing and updating.

## Quizlet import

Quizlet answers include a compact reference such as “(cf. Section 8.1)”, without URLs. Attribution and licensing are provided below and should accompany shared sets.

The text files are ready for later use; an account is only needed when creating a set in Quizlet. On the Quizlet website, create a flashcard set and choose Import. Open the downloaded text file, copy all its contents, and paste it into the import box. Select a tab between question and answer and a new line between cards. Check the preview and set both languages to English before creating the set. There is no heading row to remove. [Quizlet import instructions](https://help.quizlet.com/hc/en-us/articles/360029977151-Creating-sets-by-importing-content).

The combined Quizlet set contains the complete core set plus the advanced questions. Use it as an alternative to the Core set to avoid studying the same core questions in two separate sets.
