# Apps

Choose an activity or calculation tool. Start with the [core tutorial route](book/#core-route), or [open the tutorial and an activity together](study/). The [advanced route](book/#advanced-route) adds simulations, precision planning and other designs.

## Core: basic calculations and justification

- [Two proportions](two_proportions/): compare event percentages in two independent groups.
- [Two means](two_means/): compare mean outcomes in two independent groups.
- [Dropout adjustment](dropout_adjustment/): allow for expected losses when setting recruitment targets.
- [Record the assumptions](study/?activity=assumptions_report): write a study plan and generate a report.

## Explore further

- [Sample size reasoning lab](power_explorer/): starts with basic calculation controls; select **Explore further** for advanced controls, sensitivity analyses and simulation settings. **One study** and **Many studies** are simulation extensions.
- [Estimate a proportion or pilot retention rate](prevalence_precision/): plan and interpret confidence interval precision.
- [Type I error rate, Type II error rate and power](sampling_distributions/): compare sampling distributions under the null and an alternative.
